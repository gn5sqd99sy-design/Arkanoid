# Arkanoid

Arkanoid on HTML5 Canvas ja JavaScripti abil loodud brauserimäng.

## Projekti eesmärk

Luua töötav Arkanoidi mäng, kus mängija juhib platvormi, põrgatab palli ja hävitab klotse.

## Mängu funktsioonid

- Platvormi liigutamine vasakule ja paremale
- Palli käivitamine ja põrkamine
- Klotside hävitamine
- Punktide arvestamine (10 punkti iga klotsi eest)
- Palli kaotamine ja uuesti käivitamine
- Võiduteade pärast kõigi 24 klotsi hävitamist
- Mängu taaskäivitamine
- Paus ja mängu jätkamine
- Heliefektid
- Juhtimisjuhised mänguväljal

## Juhtimine

| Klahv | Tegevus |
|---|---|
| Vasak nool | Liiguta platvormi vasakule |
| Parem nool | Liiguta platvormi paremale |
| Space | Käivita pall |
| P | Peata või jätka mängu |
| R | Alusta uut mängu pärast võitu |

## Mängu käivitamine

1. Laadi projekt GitHubist alla.
2. Paki ZIP-fail lahti.
3. Ava fail `index.html` veebibrauseris.
4. Vajuta Space, et alustada mängimist.

## Projekti failid

- `index.html` – mängu veebileht
- `game.js` – mängu loogika
- `img/` – mängu graafika
- `sounds/` – heliefektid
